# Single-cell preprocessing and visualization

Open the notebooks in order with the environment YAML in this directory. Inspect input artifact access, paths, and the data layers that each notebook uses.

## Script and notebook guide

| File | Purpose |
| --- | --- |
| [`01_quality_control.ipynb`](01_quality_control.ipynb) | Examines per-cell and per-gene quality measures and filtering choices. |
| [`02_normalization.ipynb`](02_normalization.ipynb) | Works through count normalization for comparing expression across cells. |
| [`03_feature_selection.ipynb`](03_feature_selection.ipynb) | Selects informative features for downstream analysis. |
| [`04_dimensionality_reduction.ipynb`](04_dimensionality_reduction.ipynb) | Shows dimensionality reduction and visualization after preprocessing. |
